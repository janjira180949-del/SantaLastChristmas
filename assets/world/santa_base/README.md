# The Last Workshop prop atlas

`workshop_props.png` is an original image generated for this project on 2026-10-11 using the built-in OpenAI image generation tool. It is a 1536 by 1024 RGBA atlas, six 512 by 512 cells, in row order: toy machinery, Gift Storage, Christmas tree, Letter Desk, Journey Map, Spirit Lantern. Actual corner alpha is zero. Java2D locates each cell's visible bounds once during asynchronous composition and places the separate cutouts in the authored workshop. The concept board is never loaded as runtime terrain.

The generation prompt requested a consistent high-angle top-down Christmas workshop illustration, worn walnut/brass, amber lighting, isolated complete objects and transparent margins. No external artwork, audio or third-party texture was downloaded. The user-supplied reference informed composition/mood; no reference bitmap was copied into this atlas. This records generation provenance, not an independent third-party license certification or a guarantee of copyright exclusivity. Existing supplied asset provenance is unchanged.

The original tool output remains in the user's generated-images directory; this workspace copy is permanent and is the only runtime dependency. The atlas is optional at load time: missing/invalid artwork uses the independently authored Java2D props with the same geometry. There are no audio additions. Atlas SHA-256 is recorded in `docs/SANTA_BASE_NEW_ASSETS.properties`.

`workshop_materials.png` is a second original generated image, 1254 by 1254 pixels in a two-by-two grid: walnut planks, stone foundation, cold snow and a worn Christmas carpet. It was generated with the same tool/date and the same provenance limitations. The preparation worker mirrors material swatches in memory to soften repeat boundaries and draws them only into the static cache; it does no filtering or decoding per frame. If it is missing or invalid, code-authored materials remain available. Both generated PNGs are new Base-only assets; no existing artwork is replaced.
